# Photo shot list — Villa Mima

Drop each photo in this folder with the exact filename below (`.jpg`, `.webp`, `.avif`
or `.png` all work — `.avif`/`.webp` preferred for size). Then restart `npm run dev`
(or redeploy) and the matching slot on the site renders it automatically. Until a file
exists, the site shows a tinted placeholder labelled with the slot name.

Export at roughly the recommended size (longest edge), quality ~80. Landscape unless
noted. Golden hour wherever possible — the palette is built around it.
